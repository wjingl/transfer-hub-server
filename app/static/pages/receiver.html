📥 离线收发包

完整传输内核（RaptorQR 标准二维码 + Cimbar 彩色码，发送与接收均包含）。纯本地运行，无需连接本服务器；扫描设备的摄像头接收请使用此离线包。

⬇ 下载 TransferHub-offline.zip

使用方式：解压后 Windows 双击 open-transfer-hub.bat（系统自带 PowerShell 启动，随机端口）； macOS / Linux 运行 bash open-transfer-hub.sh。浏览器会自动打开本机页面。
注意：浏览器仅允许在 HTTPS 或 localhost 使用摄像头，因此跨设备的摄像头接收请用离线包在本机打开， 或经 HTTPS 访问本服务器。
该包与服务器内置的传输内核为同一构建（字节一致），协议互通。
