📥 离线收发包

完整传输内核（RaptorQR 标准二维码 + Cimbar 彩色码，发送与接收均包含）。纯本地运行，无需连接本服务器；扫描设备的摄像头接收请使用此离线包。

⬇ 电脑离线包 TransferHub-offline.zip（Windows / macOS / Linux） 🤖 Android 应用 TransferHub-android.apk（手机直接安装）

电脑包：解压后 Windows 双击 open-transfer-hub.bat（系统自带 PowerShell 启动，随机端口）； macOS / Linux 运行 bash open-transfer-hub.sh。浏览器会自动打开本机页面。
Android 包：直接安装（需允许"安装未知应用"），打开即是完整发送/接收端，无需电脑。
注意：浏览器仅允许在 HTTPS 或 localhost 使用摄像头，因此跨设备的摄像头接收请用离线包在本机打开， 或经 HTTPS 访问本服务器。
两个包与服务器内置的传输内核为同一构建（字节一致），协议互通。
